Comment installer l'application ?

Téléchargez le fichier, ouvrez-le, puis autorisez l'installation depuis cette source si Android le demande (Paramètres → Sécurité → Sources inconnues).

Est-ce sûr ?

Le fichier est publié uniquement depuis ce site officiel Chocho SARL. Ne téléchargez jamais l'application depuis un autre lien.
